# Packaging Line 4 — Fault Code Catalog

## M4-E17: Conveyor Drive Torque Overload

Possible causes:
- Belt alignment error after replacement
- Belt tension above specification
- Obstruction on conveyor path
- Worn idler bearing

Required safety condition:
Apply lockout/tagout before inspecting any conveyor drive component.

Initial inspection:
1. Confirm the conveyor is de-energized under the lockout/tagout procedure.
2. Inspect belt tracking and tension.
3. Inspect the conveyor path for obstruction.
4. Escalate if the fault recurs after an approved inspection.
