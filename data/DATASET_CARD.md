# Dataset Card

Synthetic 2,700-row, one-second tablet-press stream for integration and evaluation. Labels: normal, compression-force high, weight variation, sticking/picking proxy, and vibration/bearing. It is not real production data, does not establish real thresholds, and must not be used for LLM fine-tuning or production decisions. Use deterministic rules first; optional anomaly ML must train only on contiguous normal windows. The sticking/picking label is only a telemetry proxy requiring physical confirmation.

The telemetry includes `tablet_hardness_kp` and `tablet_thickness_mm`, added as corroborating physical signals for the `compression_force_high` scenario. Rather than being independently randomized, both columns are derived from each row's existing `main_compression_force_kn` value (higher force yields harder, thinner tablets plus small Gaussian noise). Like the rest of the dataset, these metrics are purely synthetic demonstrations, do not establish real validation thresholds or specifications, and must not be used for LLM fine-tuning.
